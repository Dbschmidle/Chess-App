# Chess Engine + ChessBot A.I.
## Description 
This is a personal python project for learning purposes. <br>
## Deliverables <br>

1. Play against the computer (a chess bot), where the bot reflects novice play.
2. Provide an intuitive user interface using pygame
3. Minimize runtime delay by running asynchronous processes.


# How to Run
1. Install the latest version of [python](https://www.python.org/downloads/) 
2. Install the latest version of [pygame](https://www.pygame.org/download.shtml)
3. Run 'UserInterface.py'
